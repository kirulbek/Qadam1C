# Отложенные задачи Qadam1C

## Авторизация и фоновая выгрузка

Дата: 08.11.2026. Статус: отложено по просьбе пользователя; текущую выгрузку не изменять.

Добавить в мастер пользователя и пароль информационной базы. Один ввод должен использоваться для выгрузки основной конфигурации и расширений; для разных баз можно задать разные данные входа. По умолчанию пароль действует только на время операции, не попадает в настройки, журналы, диагностику и Git. Отдельно оценить передачу пароля платформе: параметры процесса могут быть доступны средствам диагностики.

Добавить выполнение без стартовых диалогов 1С: прогресс, ошибки авторизации, блокировки и результат показываются в Qadam. Ошибка должна завершать операцию с понятным сообщением, а не оставлять скрытое окно ожидания. Сохранить отмену собственного процесса, проверку открытого Конфигуратора и сохранение прежних файлов/индекса при неудаче.

Предпочтительный механизм — существующий прямой запуск штатного пакетного Конфигуратора из C#. OneScript или 1С:Исполнитель возможны как оболочка, но пока не добавлять обязательную зависимость. Проверить поведение скрытого запуска на установленной версии платформы; не обещать отсутствие всех окон только на основании флагов запуска.

Приёмка: успешный вход и выгрузка основной/расширений; неверный и пустой пароль; несколько баз с разными учётными данными; блокировка; отмена; отсутствие секретов в сохранённых файлах и сообщениях Qadam; работоспособность прежнего индекса после ошибки.
