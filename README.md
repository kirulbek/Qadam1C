# Qadam1C

**0.1.4 beta** — помощник разработчика для Конфигуратора 1С на Windows. Подсказки, шаблоны, действия с кодом и панель навигации работают локально, без встроенного ИИ.

## Скачать

На GitHub опубликованы только исходники: [архив версии v0.1.4](https://github.com/kirulbek/Qadam1C/releases/tag/v0.1.4). Готовая программа распространяется через [публикацию на Инфостарте](https://infostart.ru/public/2823706/).
Windows 10/11 x64; .NET включён в установщик. Дополнительная установка .NET для запуска готовой программы не требуется.

## Возможности

- Автодополнение ключевых слов, идентификаторов текущего текста и шаблонов возле курсора.
- Более 150 шаблонов по умолчанию, импорт `.st`, добавление и редактирование своих заготовок.
- Вставка шаблона без диалогов: `<?>` обозначает место курсора, остальные поля удаляются для ручного заполнения.
- Меню действий у текущей строки: дублирование, области, базовое форматирование, выравнивание по `=`, добавление и снятие `//` и `|`.
- Локальный индекс метаданных из отчёта по конфигурации MXL, подсказки объектов, реквизитов и имён общих модулей.
- Избранные метаданные и переход к ним в дереве Конфигуратора.
- Панель методов и областей текущего открытого модуля: поиск, переход, иконки процедур и функций, номера строк, сворачивание областей.
- Перетаскивание методов внутри области и между областями. Сначала меняется план в панели, затем кнопка «Применить порядок» вносит изменения в 1С. «Отменить» сбрасывает план.
- Проверка пустых строк вокруг переносимого метода, сохранение комментариев и директив с методом.
- Независимое включение блоков навигации и избранного, прикрепление панели справа к 1С.
- Крестик очистки в полях поиска, настройка автозапуска вместе с Windows.

## Начало работы

1. Установите и запустите Qadam1C.
2. Откройте модуль в Конфигураторе и наберите `Сооб`.
3. `Tab` принимает подсказку, стрелки выбирают вариант, `Esc` закрывает список; `Ctrl+Alt+Пробел` вызывает подсказки вручную.
4. `Ctrl+Alt+Enter` открывает меню действий, `Ctrl+D` дублирует строку.
5. Панель разработчика, шаблоны и «Мои конфигурации» доступны через значок Qadam1C возле часов.
6. `Ctrl+Alt+B` добавляет текущий объект из дерева или модуля в избранное.

Пользовательские данные установленной версии хранятся в `%LOCALAPPDATA%\Qadam1C\data`.
При переносе методов создаётся локальная резервная копия текста в `module-move-backups` внутри каталога данных. В публичный репозиторий резервные копии не входят.

## Сборка из исходников

### Подключение баз через мастер

При обычном запуске открывается «Подключение баз»; также мастер доступен через значок возле часов → «Подключить базы / обновить выгрузку…».

1. Отметьте базы из зарегистрированного списка 1С. Локальные и общие файловые списки поддерживаются; веб-подключения не показываются.
2. Один раз выберите общую локальную папку. Для каждой базы создаётся свой каталог с названием и коротким идентификатором, внутри — `Основная` и `Расширения/<имя>`.
3. Выберите подходящий установленный `1cv8.exe`. Если версия указана в списке баз, мастер проверяет совпадение; базы разных версий выгружайте отдельно.
4. Сохраните изменения и закройте Конфигуратор выбранной базы. Нажмите «Выгрузить и подключить». При необходимости войдите в штатном окне 1С; Qadam не сохраняет пароль.
5. После сообщения о готовности откройте Конфигуратор. Основная конфигурация подключается по адресу базы, расширения учитываются отдельно по имени в заголовке редактора. При неизвестном имени расширения основной индекс не подставляется вместо него.

Мастер использует только `DESIGNER /DumpConfigToFiles`, для расширений — `-AllExtensions`, формат `Hierarchical`. Загрузку и обновление конфигурации базы он не выполняет. Локальные открытые Конфигураторы проверяются до запуска; удалённую блокировку сообщает сама 1С. Если база открыта, но её адрес определить не удалось, мастер просит закрыть это окно после сохранения, а не угадывает соответствие.

Новая выгрузка сначала создаётся в `.подготовка`. После проверки XML и индексации BSL она заменяет рабочий каталог; прежняя версия остаётся в `.предыдущие`. При сбое публикации выполняется откат. При отмене завершается только запущенный мастером пакетный процесс. Незавершённые папки и журналы сохраняются для разбора; автоматической очистки нет. Снятие флага расширений означает, что после успешной выгрузки подключённой останется только основная конфигурация.

Индекс модулей `.qadam-modules.json` содержит относительные пути BSL, SHA256 и процедуры/функции с параметрами и строками. Это основа последующего поиска; полного семантического анализа и новой панели глобального поиска пока нет. Точность эвристического разбора ограничена возможностями `ModuleOutline`.

После `ИмяОбщегоМодуля.` Qadam читает из этого индекса экспортные методы, показывает параметры и вставляет вызов со скобками. Уже набранные скобки не дублируются. В модуле расширения используются основная конфигурация и выбранное расширение; одинаковые имена методов показываются один раз с сигнатурой из расширения. Заголовок расширения сопоставляется с именем или синонимом из XML; неоднозначное соответствие не выбирается. Индекс читается в фоновом потоке и кэшируется до изменения файла. Это подсказки по сохранённой выгрузке: доступность методов в клиентском/серверном контексте и директивы перехвата расширений пока полностью не анализируются.

В списке методов выберите строку и нажмите **Alt+F12**: Qadam откроет определение в отдельном окне только для чтения, выделив объявление метода. Вставлять вызов перед просмотром не нужно. **Esc** закрывает просмотр и возвращает в исходное окно 1С. Это код сохранённой выгрузки, а не живой редактор Конфигуратора: несохранённые изменения 1С в нём отсутствуют. Перед открытием проверяется хеш файла; изменённый файл с устаревшим индексом не открывается по старой позиции.

### Ручное добавление готовой выгрузки

1. В Конфигураторе выполните «Конфигурация → Выгрузить конфигурацию в файлы…». Выберите иерархический формат и отдельную папку для базы. Дождитесь завершения.
2. Откройте «Мои конфигурации → Добавить папку…». Выберите корень выгрузки с `Configuration.xml` и `ConfigDumpInfo.xml`. Запущенная 1С для добавления папки не нужна.
3. Назовите запись понятно, например «УНФ — тестовая», через «Переименовать…».
4. Во втором шаге выберите окно нужной базы и нажмите «Использовать в этой базе». Проверьте соответствие базы и выгрузки: автоматически определить его по папке нельзя.
5. После изменений повторите ручную выгрузку в ту же папку и нажмите «Перечитать файлы». Qadam не запускает выгрузку сам.

При ручном добавлении папка XML даёт список объектов, полей и типов реквизитов; файлы BSL подсчитываются. Индекс методов создаётся мастером выгрузки. Для автоматического подключения расширений используйте мастер. Старые сохранённые подключения MXL совместимы.

Подсказки после точки учитывают создание документов/элементов, ссылочные реквизиты, строки табличных частей, ключи структур и колонки строк таблицы значений. Анализируются простые присваивания, алиасы, цикл «Для каждого», добавление/удаление полей, а также возврат локальной функции или экспортной функции общего модуля. Допускается описание возвращаемого значения в комментарии функции. Соответствия пока исключены. Это ограниченный статический анализ: динамические имена, составные типы и сложные потоки выполнения могут не дать подсказку. Код BSL не исполняется. Текущий модуль берётся из редактора; общие модули и метаданные — из последней выгрузки. После изменения конфигурации обновите выгрузку.

«Убрать из списка…» удаляет только запись Qadam и её подключения, сохраняя исходные файлы и базу. Ошибка или отмена перечитывания сохраняет прежний список. Автоматическое сканирование через окна 1С больше не предлагается в основном окне.

### Команды сборки

Нужны Windows x64 и **.NET SDK 8**. Проект использует WinForms, UI Automation и WinAPI; сторонних NuGet-пакетов нет.

```powershell
dotnet restore -r win-x64 --source https://api.nuget.org/v3/index.json
dotnet publish -c Release -r win-x64 --self-contained true --no-restore -o release/app
.\release\app\Qadam1C.exe
```

Для сборки установщика нужен Inno Setup 6: разместите его компилятор в `installer/tools/inno/ISCC.exe`, затем выполните:

```powershell
powershell -ExecutionPolicy Bypass -File installer/Build.ps1
```

Скрипт создаёт чистую сборку, запускает проверки и собирает `release/Qadam1C-Setup-0.1.4-x64.exe`.
Inno Setup и .NET SDK не входят в исходники и распространяются их авторами отдельно.

## Проверки

После публикации приложения:

```powershell
.\release\app\Qadam1C.exe --completion-test
.\release\app\Qadam1C.exe --smart-completion-test
.\release\app\Qadam1C.exe --favorites-test
.\release\app\Qadam1C.exe --snippet-test
.\release\app\Qadam1C.exe --outline-test
```

Нулевой код завершения означает успех. Для проверки показа окон нужен доступный интерактивный рабочий стол Windows.
Основные ручные проверки проводились на 1С 8.3.27.1936; отдельные ранние проверки — на 8.5.1.1150. Совместимость со всеми версиями платформы не заявляется.

## Ограничения бета-версии

Форматирование базовое; полного семантического анализа BSL нет. Отчёт MXL содержит структуру метаданных, но не тексты модулей: экспортные методы общих модулей из одного отчёта не индексируются.
Работа на других версиях 1С, с разным DPI и несколькими мониторами требует проверки. Начинайте тестирование изменений кода в тестовом модуле; после применения перестановки доступна отмена через `Ctrl+Z` в 1С.

Сценарий получения MXL-отчёта управляет интерфейсом открытого Конфигуратора. Перенос в несовместимую ветвь условной компиляции блокируется. Если исходный текст изменился после планирования перестановок, применение отменяется.

Сканер использует проверенные нажатия элементов вместо вызова UI Automation Invoke. Добавлены журналы `metadata-scan.log` и `metadata-error.log` в каталог пользовательских данных.
