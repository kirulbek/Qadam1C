# Qadam1C

**0.1.3 beta** — помощник разработчика для Конфигуратора 1С на Windows. Подсказки, шаблоны, действия с кодом и панель навигации работают локально, без встроенного ИИ.

## Скачать

Готовый установщик: [релиз v0.1.3](https://github.com/kirulbek/Qadam1C/releases/tag/v0.1.3).
Windows 10/11 x64; .NET включён в установщик. Дополнительная установка .NET для запуска готовой программы не требуется.

## Возможности

- Автодополнение ключевых слов, идентификаторов текущего текста и шаблонов возле курсора.
- Более 150 шаблонов по умолчанию, импорт `.st`, добавление и редактирование своих заготовок.
- Вставка шаблона без диалогов: `<?>` обозначает место курсора, остальные поля удаляются для ручного заполнения.
- Меню действий у текущей строки: дублирование, области, базовое форматирование, выравнивание по `=`, добавление и снятие `//` и `|`.
- Локальный индекс метаданных из отчёта по конфигурации MXL, подсказки объектов, реквизитов и имён общих модулей.
- Избранные метаданные и переход к ним в дереве Конфигуратора.
- Панель методов и областей текущего открытого модуля: поиск, переход, иконки процедур и функций, номера строк, сворачивание областей.
- Перетаскивание методов внутри области и между областями. Сначала меняется план в панели, затем кнопка «Применить порядок» вносит изменения в 1С. «Отменить» сбрасывает план.
- Проверка пустых строк вокруг переносимого метода, сохранение комментариев и директив с методом.
- Независимое включение блоков навигации и избранного, прикрепление панели справа к 1С.
- Крестик очистки в полях поиска, настройка автозапуска вместе с Windows.

## Начало работы

1. Установите и запустите Qadam1C.
2. Откройте модуль в Конфигураторе и наберите `Сооб`.
3. `Tab` принимает подсказку, стрелки выбирают вариант, `Esc` закрывает список; `Ctrl+Alt+Пробел` вызывает подсказки вручную.
4. `Ctrl+Alt+Enter` открывает меню действий, `Ctrl+D` дублирует строку.
5. Панель разработчика, шаблоны и метаданные доступны через значок Qadam1C возле часов.
6. `Ctrl+Alt+B` добавляет текущий объект из дерева или модуля в избранное.

Пользовательские данные установленной версии хранятся в `%LOCALAPPDATA%\Qadam1C\data`.
При переносе методов создаётся локальная резервная копия текста в `module-move-backups` внутри каталога данных. В публичный репозиторий резервные копии не входят.

## Сборка из исходников

Нужны Windows x64 и **.NET SDK 8**. Проект использует WinForms, UI Automation и WinAPI; сторонних NuGet-пакетов нет.

```powershell
dotnet restore -r win-x64 --source https://api.nuget.org/v3/index.json
dotnet publish -c Release -r win-x64 --self-contained true --no-restore -o release/app
.\release\app\Qadam1C.exe
```

Для сборки установщика нужен Inno Setup 6: разместите его компилятор в `installer/tools/inno/ISCC.exe`, затем выполните:

```powershell
powershell -ExecutionPolicy Bypass -File installer/Build.ps1
```

Скрипт создаёт чистую сборку, запускает проверки и собирает `release/Qadam1C-Setup-0.1.3-x64.exe`.
Inno Setup и .NET SDK не входят в исходники и распространяются их авторами отдельно.

## Проверки

После публикации приложения:

```powershell
.\release\app\Qadam1C.exe --completion-test
.\release\app\Qadam1C.exe --smart-completion-test
.\release\app\Qadam1C.exe --favorites-test
.\release\app\Qadam1C.exe --snippet-test
.\release\app\Qadam1C.exe --outline-test
```

Нулевой код завершения означает успех. Для проверки показа окон нужен доступный интерактивный рабочий стол Windows.
Основные ручные проверки проводились на 1С 8.3.27.1936; отдельные ранние проверки — на 8.5.1.1150. Совместимость со всеми версиями платформы не заявляется.

## Ограничения бета-версии

Форматирование базовое; полного семантического анализа BSL нет. Отчёт MXL содержит структуру метаданных, но не тексты модулей: экспортные методы общих модулей из одного отчёта не индексируются.
Работа на других версиях 1С, с разным DPI и несколькими мониторами требует проверки. Начинайте тестирование изменений кода в тестовом модуле; после применения перестановки доступна отмена через `Ctrl+Z` в 1С.

Сценарий получения MXL-отчёта управляет интерфейсом открытого Конфигуратора. Перенос в несовместимую ветвь условной компиляции блокируется. Если исходный текст изменился после планирования перестановок, применение отменяется.
